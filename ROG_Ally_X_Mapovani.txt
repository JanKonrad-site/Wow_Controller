WOW CONTROLLER 0.2.0 - ROG ALLY X / ARMOURY CRATE SE
================================================

1. Pridej skutecny WoW.exe do Game Library v Armoury Crate SE.
2. V Command Centeru nech Control Mode = Auto.
3. Otevri Game Profile hry a uprav Desktop Mode.
4. U M1 a M2 vypni "Set as Secondary Function".
5. Ve hre spust /octoport setup.

MAPOVANI
--------
Leva packa        W / A / S / D       Pohyb
Prava packa       Mouse                Kurzor / kamera / vyber z kola
A                 F9                   Akce 1 / potvrdit
B                 F10                  Akce 2 / zpet
X                 F11                  Akce 3
Y                 F12                  Akce 4
D-pad nahoru      Sipka nahoru         Predchozi pritel
D-pad dolu        Sipka dolu           Dalsi pritel
D-pad doleva      Sipka doleva         Predchozi nepritel
D-pad doprava     Sipka doprava        Dalsi nepritel
LB                Shift                Vrstva LB / docasne vypnuti auto questu
LT                Ctrl                 Vrstva LT
RB                Levy klik            Vyber v UI
RT                Pravy klik           Otaceni kamery / interakce
L3                Tab                  Dalsi nepritel - zaloha
R3                Space                Skok
Menu              F8                   Kratce menu / podrzet radialni kolo
View              Escape               Zpet / zavrit okno
M1                F                    Interakce s cilem
M2                R                    Vsechny batohy

DULEZITE
--------
A nesmi zustat namapovane na Enter. Enter otevira chat drive, nez stisk dostane
addon. Chat je ve vychozim radialnim kole a lze ho presunout na libovolnou pozici.

VE HRE
------
/octoport setup          ulozi puvodni klavesy a nastavi WOW Controller
/octoport edit           zobrazi tri vrstvy pro pretahovani schopnosti
/octoport wheel          otevre editor radialniho kola
/octoport wheel reset    vrati vychozi polozky kola
/octoport target on|off  zapne nebo vypne automaticky cil
/octoport quest on|off   zapne nebo vypne automaticke prijeti questu
/octoport mount NAZEV    nastavi mount spell nebo predmet z batohu
/octoport restore        vrati puvodni klavesy
/octoport                otevre napovedu

Poznamka: OctoWoW 1.12.2 nema nativni XInput. Desktop Mode proto prevadi
ovladac na klavesnici a mys; WOW Controller z toho uvnitr hry dela konzolove UI.
